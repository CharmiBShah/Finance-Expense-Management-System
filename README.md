# AI-Powered Personal Finance & Expense Management System

A full-stack scaffold for a personal finance and expense management application with an AI-friendly structure.

## Features
- Expense tracking and categorization
- Budget overview dashboard
- AI-ready data flow for future analysis and recommendations
- React-based frontend and Express-based backend

## Getting Started

1. Install dependencies:
   - `npm install`
   - `npm install --prefix backend`
   - `npm install --prefix frontend`

2. Start the app:
   - `npm run dev`

## Project Structure

- `backend/` - Express API for managing expenses
- `frontend/` - React application for user interaction
