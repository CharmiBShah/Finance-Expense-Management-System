# Finance & Expense Management System

A full-stack finance and expense management application built with **ASP.NET Core Web API, C#, Entity Framework Core, SQL Server, React, and TypeScript**.

## Tech Stack

### Backend
- C#
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server
- RESTful APIs
- Swagger / OpenAPI

### Frontend
- React
- TypeScript
- Vite
- HTML5
- CSS3
